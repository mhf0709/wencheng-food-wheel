# 文成夜食签

一个适合手机打开的文成县“今晚吃什么”随机转盘。项目是纯静态 HTML/CSS/JavaScript，不需要服务器或数据库，可直接部署到 GitHub Pages。

## 功能

- 在全部候选中随机，或按烧烤、泡泡、面食、炒菜四类随机。
- 结果包含店铺、推荐菜、区域、人均、评价数和来源链接。
- 转盘停下后自动弹出结果卡片，可查看店铺、复制结果、接受安排或再转一次。
- 集成 2026-08-18 从大众点评“文成县中心城区”筛选页前 6 页读取的 90 家店铺快照。
- 集成文成拉面、伯温烧饼、珊溪包头鱼等公开地方美食资料。
- 可以添加自己的常去小店；自定义内容仅保存在当前浏览器的 `localStorage`。
- 最近五次抽签结果也保存在当前浏览器。

## 本地打开

直接双击 `index.html` 即可。为了完整测试剪贴板等浏览器能力，建议在本目录启动一个静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `wencheng-food-wheel`。
2. 将本目录文件提交并推送到仓库的 `main` 分支。
3. 打开仓库的 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub 发布，网址通常是：

   `https://你的用户名.github.io/wencheng-food-wheel/`

手机浏览器可直接打开这个地址，也可以添加到主屏幕。

## 数据说明

大众点评数据是用户验证页面后读取的一次性静态快照，并非官方 API，不会自动更新。价格、评价数、营业状态和菜单会变化，出发前应点击结果中的来源链接确认。项目没有绕过登录、验证码或平台限制。

要手工更新店铺，编辑 `data.js` 中的 `window.DIANPING_STORES`。店铺会根据名称、平台品类和推荐菜自动归入四个转盘大类；地方特色候选在 `app.js` 的 `localItems` 中维护。
